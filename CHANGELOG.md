# QuizDorm - Changelog

All notable changes to the QuizDorm platform are documented below.

## [v1.0.0] - 2026-07-23 (Production Release)

### Added
- **Phase 1.0**: Premium MVP Foundation with modern SaaS design language (Indigo/Blue/Emerald palette, dynamic glassmorphism, responsive navigation).
- **Phase 1.1**: Authentication & User Management Foundation (Login, Registration, Password Reset, Role Switcher, Session Context).
- **Phase 1.3**: Question Bank & Quiz Builder (7 question formats, MCQ, Fill-in-the-blank, Match, Sequence, Image-based, Question Picker Modal).
- **Phase 1.4**: Quiz Delivery Engine (Distraction-free exam mode, Auto-save recovery, Timer ticks, Score calculation, Answer Review).
- **Phase 1.5**: Live Competition Engine (PIN Join Lobby, Host Controls, Live Question Sessions, Animated Leaderboards, Winner Podium).
- **Phase 1.6**: School & Organization Management (Multi-tenant workspaces, Custom Branding, Department Manager, Member Roster, Invitations).
- **Phase 1.7**: Teacher & Student Ecosystem (Classroom Management, Quiz & Homework Assignments, Academic Calendar, Announcements Board, Notification Center).
- **Phase 1.8**: Analytics, Reports & Insights (Executive Role Switcher, SVG Line/Bar/Donut Charts, Weak Topics Heatmap, Performance Insights, Multi-format Exports PDF/Excel/CSV).
- **Phase 1.9**: Production Hardening & Release (Security headers, XSS/CSRF sanitizer, Error Boundaries, PWA Manifest, SEO Sitemap/Robots, System Health Dashboard).
